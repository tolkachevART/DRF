# Платформа для онлайн-обучения

Бэкенд-сервер для платформы онлайн-обучения, позволяющий пользователям создавать, публиковать и управлять учебными курсами и материалами.

## Особенности

- Регистрация и аутентификация пользователей
- Создание, редактирование и удаление курсов
- Публикация учебных материалов (видео, документы, презентации и др.)
- Возможность подписки на курсы
- Управление подписками пользователей

## Стек технологий

- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT-аутентификация
